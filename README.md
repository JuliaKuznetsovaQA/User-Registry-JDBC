# Система регистрации и авторизации пользователей (ModuleRegAuth)

Учебный проект консольного приложения на Java, демонстрирующий работу со списками, файлами JSON и реляционными базами данных, а также применение архитектурных паттернов проектирования.

## 🚀 Стек технологий
* **Java 25 (LTS)** — актуальная версия платформы.
* **PostgreSQL** — реляционная система управления базами данных.
* **JDBC** — взаимодействие с БД напрямую через SQL-запросы.
* **Google Gson** — библиотека для сериализации данных в формат JSON.

---

## 🛠 Реализованная функциональность
Проект выполнен в рамках учебного задания и разделен на три этапа хранения данных (используется паттерн **DAO**):
1. **In-Memory (Список):** Хранение пользователей в динамической памяти (`LinkedList`). Данные удаляются после остановки приложения.
2. **Файловая система (JSON):** Сохранение состояния между запусками программы в файл `user.json` с помощью библиотеки Gson.
3. **База данных (SQL):** Полноценный **CRUD** (Create, Read, Update, Delete) для управления пользователями в таблицах PostgreSQL через JDBC.

---

## 📐 Примененные паттерны проектирования (GoF)
В архитектуре проекта успешно реализованы два порождающих паттерна:
* **Singleton:** Класс `DbManager` гарантирует создание строго одного постоянного подключения к базе данных на всё приложение, защищая систему от утечек ресурсов.
* **Factory Method:** Интерфейс `DaoFactory` изолирует логику метода `main` от конкретных реализаций (файлы или БД). Смена источника данных происходит изменением одной строки кода.

---

## 💻 Интерактивная авторизация
В методе `main` реализована живая консольная форма (через `Scanner`) с подробным разбором причин неудачного входа:
* Предупреждение, если логин не зарегистрирован в системе.
* Предупреждение, если логин верный, но пароль введен неверно.
* Приветствие `"Добро пожаловать!"` при успешном совпадении данных.
